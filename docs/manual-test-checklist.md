# 本地完整验收清单

这份清单覆盖目前所有用户可见功能。备案未完成也可以在微信开发者工具模拟器中执行。

## 1. 自动化检查

```bash
./mvnw test
npm test
```

预期：

- Maven 显示 `BUILD SUCCESS`。
- Node 显示“小程序静态校验通过：14 个页面”，并通过商品规格编辑器测试。

## 2. 启动与初始化

1. 运行 `./mvnw -pl backend spring-boot:run`。
2. 打开 `http://127.0.0.1:8080/actuator/health`，确认 `status` 为 `UP`。
3. 微信开发者工具导入仓库根目录，关闭合法域名校验并编译。
4. 在邀请页切换为商家，使用 `LOVE-MERCHANT`，确认进入商家订单页。
5. 打开“小店设置”，点击“允许新单提醒”；本地应显示 `accept`。
6. 点击“切换为顾客”，使用 `LOVE-CUSTOMER`，确认进入今日菜单。

## 3. 顾客功能

- 分类切换后商品列表会变化。
- 搜索“奶茶”能找到示例奶茶。
- 打开奶茶，不选必选规格时不能加入购物篮。
- 选择温度和甜度，调整数量后加入购物篮。
- 再加入“抱抱券”，购物篮数量正确。
- 在购物篮增减数量，合计心意值同步变化。
- 填写留言并下单，进入“下单成功”页面。
- “我的订单”能看到订单、状态、明细、留言和时间线。
- 新建另一订单，在商家接单前点击取消，状态变为“已取消”。

## 4. 商家订单功能

1. 顾客首页点击“本地验收：切换到商家”。
2. 待处理筛选能看到刚才的订单。
3. 打开订单，核对顾客昵称、商品规格、数量、合计和留言。
4. 留言“马上安排”并点击“接受订单”。
5. 再依次点击“开始准备”“已经完成”。
6. 返回订单详情，确认时间线完整且状态为“已完成”。
7. 尝试取消已完成订单，应被后端拒绝。

Java 终端会出现类似 `LOCAL WECHAT NOTICE` 的日志，分别代表新订单通知和状态通知。

## 5. 商家商品功能

- 分类管理：新增分类、编辑名称/排序、隐藏分类。
- 删除含商品的分类时，确认后端阻止误删。
- 商品管理：新增商品、选择分类、设置心意值和库存。
- 上传图片，确认列表和顾客页可以显示。
- 使用可视化编辑器创建必选单选规格和可选多选规格。
- 新增、删除和上下移动规格组、规格选项，确认顾客端顺序一致。
- 关闭“立即上架”，确认顾客列表不可见。
- 再次上架，确认顾客可见。
- 编辑商品后，历史订单仍保留原商品名、规格和价格快照。
- 删除无历史约束冲突的测试商品。

## 6. 邀请与权限

- 商家设置生成新顾客邀请码，复制后确认格式正确。
- 换一个新的调试 OpenID 调用兑换接口，邀请码可用一次。
- 顾客直接请求 `/api/merchant/categories` 应返回 `403`。
- 连续输入错误邀请码后应收到频率限制。
- 同一个下单幂等键重复请求不会产生第二个订单。

## 7. 通过标准

自动化测试通过，以上页面无白屏，顾客不能进入商家接口，订单状态严格按顺序流转，Java 日志能看到模拟通知，即可认为备案前功能验收完成。
